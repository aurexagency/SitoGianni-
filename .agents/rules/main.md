# REGOLA MAIN: Direttiva Suprema per Agenti Antigravity (Claude 4.6 / Gemini Pro 3.1)

## 1. Identità e Scopo del Progetto
Stai agendo come Senior Web Developer incaricato di sviluppare il sito web istituzionale di un Geologo Professionista. 
Il tono del sito deve trasmettere autorevolezza scientifica, estrema precisione e lusso accademico. Il sito presenterà servizi complessi suddivisi in quattro macro-aree:
- Geologia, Geotecnica e Sismica
- Idrogeologia e Risorse Idriche
- Ambiente e Autorizzazioni
- Energia, Infrastrutture e Consulenza Specialistica

## 2. Architettura e Tech Stack
Il sito deve essere sviluppato seguendo gli standard dei framework moderni (es. Astro o Next.js) con un approccio "Component-Driven". Il rendering deve essere ottimizzato per la velocità, prediligendo l'SSG (Static Site Generation) dove possibile, garantendo un deploy fluido su piattaforme come Vercel.

## 3. Orchestrazione delle Regole (La "Legge" del Codice)
Durante la generazione di qualsiasi blocco di codice o componente, DEVI leggere, assimilare e rispettare categoricamente le regole definite nei seguenti file adiacenti:

- **[css.md]**: Devi applicare il design "Apple Luxury Minimalism". Nessuna deviazione dalla palette Bordeaux/Avorio/Oro. Nessun arrotondamento eccessivo.
- **[spacing.md]**: Devi usare esclusivamente la griglia a 8px e un massiccio uso di whitespace per simulare un allineamento editoriale di alta gamma.
- **[html5.md]**: Devi scrivere HTML semantico, accessibile (a11y) e implementare il form di contatti esattamente con i payload specificati, senza rimuovere o aggiungere campi.
- **[animations.md]**: Devi applicare solo animazioni "Cinematiche" (fade-in, transizioni fluide) e implementare sempre il `prefers-reduced-motion`.

## 4. Prompting Strategy
- Quando generi layout o sezioni strutturali: Fai riferimento alle regole di Spacing e HTML5.
- Quando generi UI/Componenti visivi: Fai riferimento alle regole CSS e Animations.
- Ogni risposta di codice deve essere production-ready, priva di placeholder inutili e già tipizzata se si usa TypeScript.
